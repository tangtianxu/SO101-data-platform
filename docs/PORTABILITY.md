# 可移植性与验收清单

这是公开源码快照的已知限制，不是已完成的承诺。原机器可以使用不意味着其他机器能直接使用。

## 需要迁移的固定绑定

| 项目 | 主要位置 | 当前行为 |
| --- | --- | --- |
| 数据根、缓存、解释器 | `common.py`、启动脚本、配置模板 | 固定 E 盘，不接受任意安装位置 |
| 正式运行入口 | `desktop.py`、`app_identity.py`、桌面脚本 | 防止本机多副本混跑；不接受任意克隆路径 |
| 设备身份 | `common.py`、`runtime/shared_scripts/so101_record_supplement.py`、`so101_guarded_real_replay.py`、`so101_act_shadow.py` | 已脱敏为占位符，仍须明确核对自己的 USB 设备和角色；影子脚本还有旧 COM10 检查 |
| 主臂标定位置 | `worker.py` | 仍使用旧固定路径 |
| 起点与动作范围 | 配置、任务起点、标定、软件限位 | 坐标绑定，不能复用其他设备的标定或把限位当作自动避障 |
| 外部适配代码 | `runtime/`、`config.example.json` | 代码已附带，但尚未自动处理安装位置映射 |
| 历史数据兼容 | `signal_tools.py`、`dataset_library.py`、部分测试 | 含特定历史数据的映射、保护和 fixture；不包含对应数据 |

## 依赖与数据兼容

- `environment.observed.json` 记录版本，不是完整依赖锁。源码依赖 LeRobot 的具体 API 和本机修改；普通 pip 安装同版本不等于完全复现。
- `runtime/patches/lerobot-local.patch` 是原开发 checkout 的工作区差异，不包含上游整个仓库，也不宣称对任意 LeRobot 版本可直接应用。
- 独立窗口依赖 Windows 和系统 WebView2。尚未验证 Linux、macOS 或无桌面系统。
- 第一版数据查看/裁剪主要适配本机 LeRobot v3 数据布局。旧格式、缺相机或缺数值字段的数据需逐项检查。
- 当前配置初始化将部分离线功能与模型/标定文件存在性耦合；通用版应改为按功能验证，不能通过使用假标定解决。

## 真机仍需验收

- 主从臂身份、角色、标定和相机 Top/Wrist 映射。
- 预览与只读监控/基本控制同时运行。
- 力矩开关写入与回读、停止和退出时的实际行为。
- 低速同步后录制、Space/Esc、续录、保存与异常退出。
- 扩展寄存器读数的单位、时间戳与真实采样频率。
- ACT 回流录制打开后的控制频率、保存完整性和异常处理。
- 用自己的起点、边界、模型与清空的路径重新验收复位/回放/推理。

## 后续通用化方向

1. 使用可配置工作区、相对资源路径与独立用户配置。
2. 首次配置向导负责设备绑定、标定选择、相机角色和依赖检查。
3. 默认不载入任何他人的模型、起点或安全配置；保持失败关闭。
4. 将与旧实验相关的时间上限和历史映射改成明确的任务配置。
5. 提供经过新机器验证的安装清单和完全使用合成 fixture 的测试。

本次发布不自动修改原本机的工作流或放宽任何设备边界。
